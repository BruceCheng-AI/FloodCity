## 项目来源与 GitHub

- **项目初始来源：深城纪** — [linranff/GTA_SZ](https://github.com/linranff/GTA_SZ)。FloodCity 的城市游戏基础源自该项目。
- **FloodCity 公开版本** — [BruceCheng-AI/FloodCity](https://github.com/BruceCheng-AI/FloodCity)，供大家在线体验洪水演练。

这是专供公开访问的游戏构建。角色使用项目自有的外卖骑手和咖啡馆角色；原包禁止二次配布的角色模型未包含在此仓库。地图与第三方素材的署名见 [`licenses/`](licenses/) 和游戏内说明。

本仓库仅保存公开构建，不包含本地对话归档、原始下载包或开发缓存。
