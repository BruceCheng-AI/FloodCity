# FloodCity

浏览器试玩地址：[打开 FloodCity](https://brucecheng-ai.github.io/FloodCity/)。

洪水演练介绍：[了解淹没、车速衰减与避水路线规划](https://brucecheng-ai.github.io/FloodCity/flood-guide.html)。

这是专供公开访问的游戏构建。角色使用项目自有的外卖骑手和咖啡馆角色；原包禁止二次配布的角色模型未包含在此仓库。地图与第三方素材的署名见 [`licenses/`](licenses/) 和游戏内说明。

源码开发仓库来源：[linranff/GTA_SZ](https://github.com/linranff/GTA_SZ)。本仓库仅保存公开构建，不包含本地对话归档、原始下载包或开发缓存。
